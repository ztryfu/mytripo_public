# 0002 codex 가 턴어라운드 시트를 만들고 claude 가 구조를 읽는다

## 결정
- codex 구독(`image_gen`)은 앞·옆·뒤가 한 장에 든 턴어라운드 시트를 만든다. 사용자가 생성과 수정을 지시하고, 결과를 보고 진행을 고른다.
- claude 구독(`claude -p --json-schema`)은 사진이나 시트를 보고 구조(앞·옆·뒤, 관절점, 부위별 색)를 읽는다.
- 메시는 0001 대로 Rust 가 만든다. AI 는 메시를 직접 만들지 않는다.

## 근거
- 세 시점을 따로 생성하면 시점마다 비율과 색이 어긋난다. 한 장에 함께 그리면 같은 피사체·크기·바닥선을 지키기 쉽다. 실루엣 단면 로프트는 세 시점이 맞을 때 IoU 가 높다.
- 생성 결과는 매번 다르다. 사람이 시트를 보고 고르는 단계가 메시 계산 전에 있어야 한다.
- 시트 프롬프트에 직교 시점·A포즈·단색 배경·그림자 없음을 넣으면 로컬 마스크와 단면 측정이 그대로 동작한다.

## 버린 안
- claude 가 메시나 Blender 스크립트를 직접 만드는 방식: 0001 의 버린 안과 같은 이유로 버렸다.
- 시점마다 이미지를 따로 생성하는 방식: 시점 사이 일관성이 낮다.
